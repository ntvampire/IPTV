# 📺 IPTV Playlist & EPG

Персональный самообновляемый IPTV-плейлист с отборными музыкальными каналами (семейство Trace, XITE, Afrobeats) и популярными телеканалами, объединенными с актуальной программой передач (EPG) и качественными логотипами.

> Ссылка на EPG уже включена в заголовок плейлиста (`url-tvg`). В большинстве современных плееров (TiviMate, OTT Navigator, Televizo, Apple TV и др.) достаточно указать только ссылку на плейлист — программа передач подтянется автоматически.

---

## ✨ Особенности

* **Ежедневное автообновление**: регулярная проверка доступности потоков, очистка от нерабочих ссылок и обновление расписания через GitHub Actions.
* **Резервные потоки**: автоматическое переключение на запасные ссылки при сбое основного вещания.
* **Единый стиль логотипов**: фирменные иконки в высоком разрешении с прозрачной подложкой.
* **Чистый XMLTV**: строгое соблюдение спецификации DTD без задвоений и наложений передач.
